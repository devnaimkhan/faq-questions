# Simple FAQ Accordion

An interactive and responsive **Frequently Asked Questions (FAQ) Section** built
using pure HTML, CSS, and Vanilla JavaScript. This project features a clean user
interface with smooth accordion animations.

## ✨ Features

- **Interactive Accordion:** Smooth expand and collapse animations when clicking
  on questions.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.
- **Clean UI:** Modern design with clear typography.
- **Lightweight:** Built with pure Vanilla JS, no external libraries or
  frameworks used.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styling, Flexbox/Grid, and smooth transitions.
- **JavaScript (ES6):** DOM manipulation for interactive toggle functionality.

## 📁 Project Structure

```text
├── index.html
├── style.css
└── script.js
```

## ⚙️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder.
3. Open `index.html` in your favorite browser.
